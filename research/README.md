# Research evidence register

Los registros heredados se conservan para revisión del equipo. No se han autenticado las entrevistas ni las métricas atribuidas a participantes. Una fotografía existente no acredita una entrevista, su consentimiento ni su pertenencia al segmento. Antes de usarla se debe comprobar identidad autorizada, fecha, duración, archivo o enlace accesible y transcripción con marcas de tiempo. Los enlaces de ejemplo fueron retirados de la documentación vigente.

- [Entrevistas del README remoto más reciente](legacy-readme-interviews.md)
- [Elicitación heredada](legacy-elicitation.md)
- [Validación e implementación heredadas](legacy-validation-and-implementation.md)

Los capítulos 2 y 5 contienen el estado vigente y el protocolo para completar evidencias. No se deben reutilizar nombres o fotografías de otra entrega para cubrir un registro faltante.

## Diferencias entre fuentes

El README remoto baseline conserva seis rutas de fotografías existentes. El capítulo separado conserva dos de esas rutas y cuatro rutas inexistentes. Además, el README registra Maria Morales y Diego Ramirez donde el capítulo registra Andrea Gómez y Jorge Quispe; algunos textos alternativos quedaron sin actualizar. Los archivos referidos por las fichas de Roberto Sánchez y Miguel Rojas se llaman Sebastian y Raul Delgado, respectivamente. Estos nombres de archivo no prueban por sí solos la identidad de las personas. El capítulo II documenta la discrepancia para que el equipo confirme la versión correcta. No se eliminan respuestas heredadas ni se sustituyen fotos para aparentar evidencia completa.
